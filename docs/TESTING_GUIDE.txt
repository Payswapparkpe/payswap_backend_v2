================================================================================
PAYSWAP - TESTING GUIDE (TDD)
================================================================================

This guide covers database reset, seeding, and comprehensive test execution.

================================================================================
DATABASE RESET AND SEEDING
================================================================================

1. CLEAN DATABASE AND RESEED (Recommended):
   python manage.py clean_and_seed --noinput

2. MANUAL STEPS:
   # Reset database (drops all tables)
   python manage.py reset_db --noinput
   
   # Run migrations (may need to fake allauth migration)
   python manage.py migrate account 0006 --fake
   python manage.py migrate
   
   # Setup roles
   python manage.py setup_roles
   
   # Seed data
   python manage.py seed_data --skip-delete

================================================================================
RUNNING TESTS
================================================================================

ALL TESTS:
   python manage.py test portal.tests --verbosity=2

SPECIFIC TEST SUITES:
   # User Manager Tests (superuser creation, role assignment)
   python manage.py test portal.tests.test_user_manager
   
   # Authentication Tests (login, signup, rate limiting, lockout)
   python manage.py test portal.tests.test_authentication
   
   # Profile Completion Tests (social signup, middleware)
   python manage.py test portal.tests.test_profile_completion
   
   # Logging Tests (IP extraction, categorization)
   python manage.py test portal.tests.test_logging
   
   # OTP Dual Delivery Tests (email + SMS)
   python manage.py test portal.tests.test_otp_dual_delivery
   
   # API Response Tests (request/response IDs)
   python manage.py test portal.tests.test_api_responses

SINGLE TEST:
   python manage.py test portal.tests.test_user_manager.UserManagerTests.test_create_superuser_auto_assigns_super_role
